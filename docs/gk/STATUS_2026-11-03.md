## 2. Phạm vi P0 vẫn phải đáp ứng

Agent Windows thu CPU/RAM/uptime; NIC và SERVICE_STATUS chưa được miễn yêu cầu. TCP length-prefix 4-byte Big-Endian/UTF-8 JSON; Agent và Admin giao tiếp với Central; Central quản lý SQL. Chỉ ACK thành công sau SQL COMMIT và dedup đúng identity. Không tự động bỏ TLS/cert verification.

Admin WinForms live login/session/RBAC/read và incident workflow chưa có nghiệm thu toàn tuyến. 40–50 máy mới là mục tiêu, không phải benchmark đã chứng minh.

## 3. Hướng cải tiến sau nhận xét giảng viên

Trọng tâm **Incident Navigator có bằng chứng**: Observe → Detect → Explain/UNKNOWN → Guided action → Verify recovery → Audit history. Không biến CPU cao hoặc Agent im lặng thành khẳng định malware/máy tắt.

E0 là kiểm chứng nhỏ: P1/P2 kiểm tra cùng dịch vụ HTTPS lab bằng DNS (resolver xác định) → TCP → TLS (hostname/cert hợp lệ) → nonce transaction. Bốn tình huống: healthy, DNS lỗi riêng P1, application HTTP 503, thiếu P2. Có fault ledger và đối chứng single-vantage/full-stack; **chưa chạy**.
