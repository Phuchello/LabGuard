   - Sinh viên B sở hữu toàn bộ logic nghiệp vụ, CSDL SQL Server 2022, xác thực PBKDF2-HMAC-SHA256 (600,000 vòng + salt 16B) và kiểm tra quyền RBAC bắt buộc phía server (`LG-B-004`).

6. **Phân định P1 Collector dùng chung:**
   - Sinh viên C phát triển **một ứng dụng Collector dùng chung (`LabGuard.Collector.exe`)** (`LG-C-013` đến `LG-C-015`).
   - Sinh viên A chịu trách nhiệm cấu hình, triển khai và kiểm thử **hai instance độc lập** của cùng một binary Collector này sau Gateway L4 (`LG-A-013` đến `LG-A-015`).
7. **Đặc thù kỹ thuật Concurrency và Threading:**
   - `rowversion` là kiểu dữ liệu đặc thù SQL Server, ứng dụng coi là token 8-byte mờ (opaque 8-byte token) để kiểm tra OCC (`LG-B-001`, `LG-B-009`).
   - WinForms điều phối luồng an toàn qua `Control.Invoke`, `BeginInvoke`, hoặc `InvokeAsync` tùy ngữ cảnh để tránh deadlock (`LG-C-006`).
